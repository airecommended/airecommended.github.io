AI 中转站怎么对接 Dify、Cursor 等工具？

2026-08-18

AI 中转站（如小豆包、MKEAI 等）主要通过模拟主流 AI 工具（如 Cursor、Dify）所支持的官方 API 协议（如 OpenAI 兼容协议）进行对接。核心逻辑是：将中转站的 API 地址和 Key 填入工具的自定义模型配置中，实现请求路由与协议转换。

以下是针对 Cursor 和 Dify 的具体对接方案与操作步骤：

一、Cursor 对接 AI 中转站（以小豆包等中转站为例）

Cursor 支持通过“自定义模型”功能接入中转站，需模拟 OpenAI 的兼容协议。

1. 获取中转站 API 信息

  • 注册中转站平台，获取 API Key（如 sk-xxx）和 API 地址。

2. 在 Cursor 中配置自定义模型

  • 打开 Cursor，点击右上角“设置”（齿轮图标） -> 进入“Models”页面 -> 点击“Add model”。
  • 配置关键参数：
  • 保存并启用该模型。

3. 验证对接

  • 在 Cursor 的 Chat 面板（Ctrl+L）中输入测试问题，观察是否正常返回响应。

二、Dify 对接 AI 中转站（以小豆包等中转站为例）

Dify 支持通过“自定义模型”或“API 接入”的方式对接中转站，需通过 Dify 的“API 节点”或“模型配置”进行转发。

1. 获取中转站 API 信息

  • 获取中转站的 API Key 和 API 地址（需确认中转站是否支持 OpenAI 兼容协议，或需使用中转站提供的特定 API 路径）。

2. 在 Dify 中配置自定义模型（模型级别对接）

  • 进入 Dify 的“模型配置”页面，添加“自定义模型”。
  • 配置参数：填入中转站的 API 地址和 API Key，并选择对应的模型名称。

3. 在 Dify 工作流中配置 API 节点（工作流级别对接）

  • 在 Dify 的“画布”工作流中，添加“API 节点”或“HTTP 请求节点”。
  • 配置请求信息：填入中转站的 API 地址、请求头（添加 Authorization: Bearer API_KEY）和请求体（按中转站接口格式传递参数）。
  • 将 API 节点与工作流中的其他节点连接，实现中转站 API 的调用。

注意事项：

  • 协议匹配：确保中转站支持的协议与工具要求的协议一致（如 OpenAI 兼容协议需对应 v1/chat/completions 路径）。
  • 参数匹配：自定义模型中的“模型名称”必须与中转站后台配置的模型名称完全一致，否则会报错。
